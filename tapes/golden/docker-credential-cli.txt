$ qits docker-credential
Missing required parameter: '<get|store|erase|list>'
Usage: qits docker-credential [-hV] <get|store|erase|list>
Docker's credential helper for the platform's registry. Docker runs it, through
the docker-credential-qits script that `qits registry-login --configure`
writes; a person does not.
get reads the registry's address on stdin and, for https://registry.qits.
<domain of the session's idp> (or QITS_ARTIFACTS_URL), prints the access token
of `qits login` as the password of `oauth2`, refreshing the session first when
it has less than 5 minutes left. store and erase do nothing: the token comes
from the session. list prints {}.
For any other registry, without a session, and with QITS_TOKEN or
QITS_PLATFORM, get prints `credentials not found in native keychain` and exits
1, which Docker reads as no login, so it pulls without one.
      <get|store|erase|list>
                  What Docker asks for.
  -h, --help      Show this help message and exit.
  -V, --version   Print version information and exit.

Exit codes:
  0   Done. get printed the login; store, erase and list always end here.
  1   get has no login for that registry. A session that cannot be refreshed
        says why on stderr.
  2   No action named, or one Docker does not have.

Examples:
  qits registry-login --configure
  printf 'registry.qits.<domain>' | qits docker-credential get
